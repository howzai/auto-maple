# Phase 2 validation notes

Use Windows 10 or 11 with the game in windowed mode for the first test pass.

Record the following for each test:

- Python version
- Display resolution and Windows scaling percentage
- Game resolution and window mode
- Whether minimap calibration succeeded
- Reported confidence and minimap dimensions
- Whether the player marker was detected
- Any console traceback or `last_error` message

Do not merge this branch into `main` until startup without the game, minimization, window closure, F12 emergency stop, and held-key release have all been verified.
